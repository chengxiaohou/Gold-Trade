# 标签判定参数可配置（风系 / 原有标签 两区分开）

## Context（为什么做）

风系加/减信号与原有形态/环境标签的判定里，散落着大量"比例/容差"硬编码值（如缩量入场的 `近20日低点×1.05`、放量突破的 `5日均量×1.2`、均线粘合的 `股价×4%` 等）。这些值是从"风轻云淡"原文转述时按盘感拍定的经验参数，没有统一入口，也无法在不用改代码的前提下微调。用户希望把这些比例参数做成**可配置项**，既能改数值、也能单独开/关每个参数，且**持久化到本地并在云(Gist)同步**。为避免混淆，**风系**标签与**原有标签**分两个区域设置。

## 参数清单（v1，仅"比例/容差"类）

> 形态内部的构造比例（如下影 ≥ 实体×2.5、×2、×0.3 等）属于形态定义标准，v1 不暴露，保持恒定，避免设置项过碎。

| 区域 | 参数 key | 含义 | 默认值 | 作用 |
| :--- | :--- | :--- | :--- | :--- |
| 风系 | `fengLowBuy` | 缩量入场·低位容差 | 1.05 | 判定 `现价≤近20日低点×值`；关=不触发"缩量入场" |
| 风系 | `fengPullback` | 回踩放量·触达容差 | 1.01 | 判定 `盘中低≤MA5×值`；关=不触发"回踩放量" |
| 风系 | `fengVolBreak` | 放量突破·倍数 | 1.2 | 判定 `今量≥5日均量×值`；关=不触发"放量突破均线" |
| 原有 | `classicDojiBody` | 十字星实体比例 | 0.05 | `实体≤振幅×值`；关=不判定十字星 |
| 原有 | `classicSmallBody` | 小实体比例 | 0.1 | `实体≤振幅×值`；关=不判定针/射/吊/倒等小实体形态 |
| 原有 | `classicNearHigh` | 接近近20日新高 | 0.95 | 形态/环境的高位判定 `收≥近20日最高×值` |
| 原有 | `classicNearLow` | 接近近20日新低 | 1.05 | 低位判定 `收≤近20日最低×值` |
| 原有 | `classicMaSqueeze` | 均线粘合比例 | 0.04 | `均线最大差<股价×值`；关=不判定"均线粘合" |

每个参数 = `{ enabled: boolean; value: number }`。每组（风系 / 原有）顶部各加一个"全部启用 / 全部关闭"总开关（批量改该组所有参数的 enabled）。

## 数据模型（types.ts）

在 `StockSettings`（[types.ts#L133-L143](file:///Users/chengxiaohou/Documents/GitHub/Gold-Trade/types.ts)）新增：

```ts
export interface TagParamEntry { enabled: boolean; value: number; }
export interface TagParams {
  feng: Record<'fengLowBuy'|'fengPullback'|'fengVolBreak', TagParamEntry>;
  classic: Record<'classicDojiBody'|'classicSmallBody'|'classicNearHigh'|'classicNearLow'|'classicMaSqueeze', TagParamEntry>;
}
export type TagParamKey = keyof TagParams['feng'] | keyof TagParams['classic'];
```

`StockSettings` 增加可选字段 `tagParams?: TagParams`。因云端同步基于整个 `stockSettings` 对象（[App.tsx#L806](file:///Users/chengxiaohou/Documents/GitHub/Gold-Trade/App.tsx#L806)），字段自动随之上云；下载恢复时在合并处（[App.tsx#L905-L916](file:///Users/chengxiaohou/Documents/GitHub/Gold-Trade/App.tsx#L905-L916)）加一行 `tagParams: result.stockSettings.tagParams ?? <default>` 即可。

## 验证

1. `npm run dev`（自动落到 3001），打开 http://10.0.0.178:3001/Gold-Trade/ ，进设置 → General：
   - 确认出现"风系标签参数"与"原有标签参数"两个独立区块，互相分隔。
2. 修改某参数数值（如放量倍数 1.2→1.5）：保存/关闭弹窗后列表"量为"标签（放量突破）与浮窗判定依据应立即按新值重算（依赖缓存 key 含 tagParams 失效生效）。
3. 关闭某参数开关（如"缩量入场"）：列表"加"标签中对应信号消失、近10日浮窗 `加仓 xN` 计数与明细相应减少。
4. 组级"全部关闭"风系开关：列表不再出现"加/减"，浮窗风系明细为空。
5. 刷新页面后数值与开关保持（localStorage `stock_dividend_settings`）。
6. 云端：设置页 Cloud 上传后，用另一处/清空 localStorage 后下载，确认参数随 `stockSettings` 恢复。
