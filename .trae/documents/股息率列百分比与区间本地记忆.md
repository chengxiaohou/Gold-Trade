# 股息率列增加历史比例显示 + 曲线区间本地记忆

## Context（背景）

用户希望"股息率"列表列做成上下两行数据（参照"持仓"列的两行样式）：

1. **上行**：维持现有的当前股息率数字（基于选中的年份，即列现值）。
2. **下行**：一个百分比，表示**当前股息率**在**股息率曲线（日线）设置的区间**内，是历史股息率的百分之多少：
   - (a) 若当前股息率 >= 区间内**历史最高**股息率 → 用区间内**次高**作分母（表现为 100% 以上）。
   - (b) 否则 → 用区间内**历史最高**作分母。

"有数据的区间" = `DividendRateCurve` 底部的 `chartRange`（最近 N 根K线，默认 120）+ `chartOffset`(回看偏移) 组成的滑动窗口。该区间需要**本地记忆**，且**日/周/月各自独立**。

已与用户确认：
- 百分比数据**只用已有缓存**（`stockBollMap`），无日线数据时该列显示 `--`，不额外发请求。
- "当前股息率" = 列表"股息率"列当前显示的值 `getDividendRate(stock)`。
- 区间持久化到 `localStorage`，日/周/月三档各自独立 key。

## 现状（已探明）

- `DividendRateCurve`（`components/StockDividendPage.tsx` L514 起）内部用 `chartRange`(默认120)/`chartOffset`(默认0) 两个 useState 管理区间，并有一个 `-`/`+` 按钮 + slider（L677-721）。每次挂载都是新实例，区间不跨周期记忆。
- 列表页股息率列：L2504-2514，td 内单行显示 `getDividendRate(stock)`。
- 列表页股息率曲线浮窗（L4057）用 `daily` K线，`title="股息率曲线"`；详情页（L3564-3570）用 `bollPeriod` 区分日/周/月。
- 每只股票的 BOLL 缓存在 `stockBollMap`（`Map<id, {daily,weekly,monthly}>`），`BollData` 含 `klines`。批量刷新后股票有日线数据；未刷新则无。
- 已有 helper：`getDividendRate(stock)`(基于选中年份)、`getDividendForYear(stock, year)`、`getSelectedYear(stock)`。

## 实现方案

### 1. 区间本地记忆（日/周/月独立）
新增一个小工具，封装 localStorage 读写，key 形如：
- `dividendChartRange_daily` / `dividendChartOffset_daily`
- `dividendChartRange_weekly` / `dividendChartOffset_weekly`
- `dividendChartRange_monthly` / `dividendChartOffset_monthly`

`DividendRateCurve` 增加 prop `period?: 'daily' | 'weekly' | 'monthly'`，内部 `chartRange`/`chartOffset`：
- 初始值从 `localStorage` 对应 `period` 读取（无则默认 120 / 0）。
- 每次 `setChartRange`/`setChartOffset` 时写回 `localStorage` 对应 key。

为支持列表页股息率列共享 daily 区间，`DividendRateCurve` 同时支持**受控**模式：
新增可选 props `rangeValue` / `offsetValue` / `onRangeChange` / `onOffsetChange`。当传入时以受控值驱动并回调；未传入则使用内部状态并写 localStorage（详情页场景）。

### 2. 主组件维护 daily 区间状态
在主 `StockDividendPage` 组件内：
- 新增 `const [dailyChartRange, setDailyChartRange] = useState(() => 读 localStorage daily)`，`dailyChartOffset` 同理。
- 修改时同步写回 `localStorage` daily key。

### 3. 列表页浮窗受控
列表页股息率曲线浮窗（L4057）给 `DividendRateCurve` 传入：
- `period="daily"`
- 受控值：`rangeValue={dailyChartRange}` `offsetValue={dailyChartOffset}` `onRangeChange={(v)=>{setDailyChartRange(v); 写localStorage;}}` `onOffsetChange={...}`。

### 4. 详情页传 period
详情页（L3564）给 `DividendRateCurve` 传 `period={bollPeriod}`（daily/weekly/monthly），内部自动按周期记忆，非受控。

### 5. 股息率列两行显示 + 比例计算
新增 helper（模块级）：
```
function calcDivRateHistoryRatio(stock, klines, range, offset, currentRate): number | null
```
- 若 `!klines?.length` 或 `stock.bollHidden` → 返回 null。
- 切片：`seg = klines.slice(-range - offset, klines.length - offset)`。
- 对每根 K 线按曲线同款算法算 rate（用 `stock.dividendByYear[年]`，回退上年，再回退 `getDividendForYear(stock, getSelectedYear(stock))`）。
- 求去重后的 `maxRate` 与 `secondMaxRate`（最大与次大的不同值）。
- `currentRate = getDividendRate(stock)`。
- 分派：`denom = currentRate >= maxRate ? secondMaxRate : maxRate`；若 `!denom || denom<=0` → null；否则返回 `(currentRate / denom) * 100`。

股息率列 td（L2504-2514）改为 `<div class="flex flex-col items-center leading-none gap-0.5">`：
- 上行：现有 `getDividendRateColor(...)` 的费率数字 `formatPercent(getDividendRate(stock))`。
- 下行：`<span class="font-mono text-[9px] text-app-rowtext opacity-60">` 显示 `Math.round(ratio)` + `%`；无数据显示 `--`。参照用户偏好的灰色小字（同持仓列下方百分比样式）。

## 涉及文件
- `components/StockDividendPage.tsx`（主要改动：`DividendRateCurve` 记忆与受控、主组件 daily 区间状态、股息率列两行、helper）。
- 无需修改 `types.ts`（区间存 localStorage，不进云端/stockSettings）。

## 验证
- 本地 `npm run dev`（或既有 dev server）启动，打开股息率列表：
  1. 列表页已批量刷新（或打开详情产生缓存）的股票，股息率列下方出现百分比；未缓存的显示 `--`。
  2. 调整列表页股息率曲线浮窗的 `-`/`+`/slider，列下方百分比随区间变化。
  3. 详情页切换日/周/月分别调整区间后，刷新页面确认三档区间各自被记忆、互不影响。
  4. 当前股息率为区间最高时，百分比应 >100（用次高作分母）。
