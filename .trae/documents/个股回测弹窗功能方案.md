# 个股回测弹窗功能方案

## Context

用户希望为股息率项目增加个股回测功能。回测策略以现有标签系统（风系加/减、K线形态、环境量价、破位等）作为买卖信号，在 500 条前复权日K线上运行策略回测，将买卖点标注在K线图上，并与操作记录列表一一对应。

## 关键决策

- **入口**：在现有 MktInfo 弹窗标题栏加「回测」按钮，点击后打开回测弹窗
- **标签范围**：全部标签可用作信号，用户在策略编辑器中自定义"标签→操作（买入/卖出，仓位百分比）"映射
- **K线图**：引入 `klinecharts@^10.0.3`（40kb gzip，零依赖，原生蜡烛图+买卖点标注+移动端支持）
- **标签联动**：`tagParams` 作为 prop 透传给 `BacktestModal`，参数变化触发 `useMemo` 重算回测，天然实现联动

// 回测策略规则
export interface BacktestRule {

### 3. `services/backtestEngine.ts` — 新建，纯函数回测引擎

```ts
export function runBacktest(
  klines: BollKline[],
  strategy: BacktestStrategy,
  tagParams: TagParams,
  fmt: (v: number) => string,
): BacktestResult
```

执行步骤：
1. **预计算每根 bar 的标签集合**（只算一次，O(n)）：
   - 调用改造后的 analyzer 全程遍历，构建 `tagsByBar[i]: Set<string>`（稳定 tagKey）
2. **逐日遍历执行策略**：
   - 先执行卖出规则、再执行买入规则（先平仓再开仓）
   - 每笔记录推入 trades（id = `${date}-${tagKey}-${seq}`）
3. **期末结算**：finalValue = cash + shares × lastClose；统计胜率、最大回撤

**性能**：500 根 × 4 分析器全程调用，`useMemo([klines, strategy, tagParams])` 缓存。

### 4. `components/BacktestModal.tsx` — 新建，回测弹窗主组件

**内部子组件（同文件内定义）**：

- **`BacktestModal`**（根容器）：`createPortal` 渲染，`fixed inset-0 z-[9999]`，三栏布局
- **`StrategyEditor`**（策略编辑器）：规则列表，每行=标签下拉→买/卖→仓位%→删除，底部"新增规则"+"运行回测"
- **`BacktestKlineChart`**（K线图）：klinecharts 封装，`applyNewData` + `setMarks` 标注买卖点，点击 mark → `onSelectTrade(id)` 高亮列表
- **`BacktestTradeList`**（操作记录表）：日期/标签/操作/价格/股数/金额/持仓/盈亏，行点击→高亮 K线图对应 mark
- **`BacktestSummary`**（统计概览条）：初始资金/期末市值/总收益率/胜率/最大回撤/交易次数

**标签目录常量**（`BACKTEST_TAG_CATALOG`）：硬编码约 20 项，按 group 分组：
- `feng-add-*`：缩量入场/放量突破/回踩放量/缩量止跌/主力不破位
- `feng-reduce-*`：缩量急拉/新高量能不足/急跌破20日线/放量破位
- `pattern-*`：十字星/金针探底/吊颈线/射击之星/倒锤子线
- `env-*`：量增/量缩/布林扩张/布林收口
- `break-*`：真破位/假破位

## 数据流

```
App.tsx (tagParams, 云端同步)
  └─ StockDividendPage
       ├─ stockBollMap (已有 500 条 K线缓存)
       ├─ tagParams prop
       ├─ MktInfo 弹窗 → [新增]「回测」按钮 → setBacktestStock
       └─ <BacktestModal>
              ├─ props: stock, klines(stockBollMap), tagParams, apiSource
              ├─ state: strategy, result(useMemo), selectedTradeId
              ├─ 引擎: runBacktest(klines, strategy, tagParams)
              └─ 子组件: StrategyEditor / KlineChart / TradeList / Summary
```

**标签联动链路**：设置页改 tagParams → App setState → re-render → BacktestModal props 变 → useMemo 失效 → runBacktest 重算 → 图表 marks 与操作记录同步刷新。

## 关键注意事项

1. **未来函数风险**：`analyzeMarketConditions` 破位判定有 t+1/t+2 前瞻（L726），回测时当天无法知道真/假破位，引擎应在 status 定型日（t+2）才触发信号，而非破位当天
2. **同日多信号**：同一日可能同时命中加仓和减仓标签，引擎约定先卖后买（先平仓再开仓）
3. **K线数据复用**：直接从 `stockBollMap` 取已有的 daily klines，不主动发起请求
4. **移动端适配**：复用 EditTagBubble 的拖拽+定位模式，`max-h-[90vh] flex flex-col` + 内部 `overflow-y-auto`
