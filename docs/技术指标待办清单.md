# 技术指标待办清单

> 从现有 K 线数据（open/close/high/low/volume）可计算的技术指标，无需额外调接口。

## 现有数据源

| 数据源 | 接口 | 返回数据 |
|-------|------|---------|
| 腾讯 | `/appstock/app/fqkline/get` | 原始 K 线（open/close/high/low/volume/date） |
| 新浪 | `/quotes_service/api/json_v2.php/CN_MarketData.getKLineData` | 同上 |

MA 和 BOLL 已在代码中计算，其余指标需新增计算函数。

## 指标清单

### 1. KDJ（随机指标）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★☆☆☆☆ 简单 |
| 需要的数据 | high, low, close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | RSV = (close - Ln) / (Hn - Ln) × 100；K = 2/3 × prevK + 1/3 × RSV；D = 2/3 × prevD + 1/3 × K；J = 3K - 2D |
| 参考价值 | ★★★★★ A 股散户最常用的指标，金叉买/死叉卖判断直观，适合在详情弹窗新增选项卡展示 |

### 2. MACD（指数平滑异同移动平均线）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★★☆☆☆ 简单 |
| 需要的数据 | close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | DIF = EMA12(close) - EMA26(close)；DEA = EMA9(DIF)；MACD 柱 = 2 × (DIF - DEA) |
| 参考价值 | ★★★★★ 机构/量化标配，全球通用的趋势跟踪指标，零轴上方多头、下方空头，柱状图缩头/伸长判断力度 |

### 3. RSI（相对强弱指数）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★☆☆☆☆ 简单 |
| 需要的数据 | close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | 计算 n 日内涨幅均值和跌幅均值，RS = 涨幅均值 / 跌幅均值，RSI = 100 - 100 / (1 + RS) |
| 参考价值 | ★★★★☆ 超买（>70）超卖（<30）判断直观，适合与 KDJ 配合使用，减少 KDJ 钝化时的误判 |

### 4. WR（威廉指标 / Williams %R）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★☆☆☆☆ 简单 |
| 需要的数据 | high, low, close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | WR = (Hn - close) / (Hn - Ln) × (-100) |
| 参考价值 | ★★★☆☆ 与 KDJ 原理相似，超买超卖判断，但敏感度更高，适合短线参考。可作为 KDJ 的补充验证 |

### 5. BIAS（乖离率）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★☆☆☆☆ 极简单 |
| 需要的数据 | close, MA |
| 数据来源 | 已有 K 线数据和 MA 计算结果 |
| 计算方式 | BIAS = (close - MA(n)) / MA(n) × 100% |
| 参考价值 | ★★★★☆ 价格偏离均线的程度，判断回调/反弹概率。已有 MA 数据，实现成本几乎为零 |

### 6. ROC（变动率）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★☆☆☆☆ 极简单 |
| 需要的数据 | close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | ROC = (close / close(n日前) - 1) × 100% |
| 参考价值 | ★★☆☆☆ 动量指标，简单直观。但与其他指标重合度较高，优先级可以放低 |

### 7. VOL（成交量柱状图）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★☆☆☆☆ 已有数据，只需渲染 |
| 需要的数据 | volume |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | 直接展示成交量数据，可按日/周/月聚合 |
| 参考价值 | ★★★★★ 量价配合分析基础，放量突破/缩量回调等形态判断，数据已有，加一个柱状图几乎零成本 |

### 8. EMA（指数移动平均线）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★☆☆☆☆ 简单 |
| 需要的数据 | close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | EMA = close × α + prevEMA × (1 - α)，其中 α = 2 / (n + 1) |
| 参考价值 | ★★★☆☆ 比 SMA 更灵敏，是 MACD 的基础。但已有 SMA 8 条均线，EMA 的增量信息有限，优先级可放低 |

### 9. CCI（商品通道指数 / Commodity Channel Index）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★★☆☆☆ 中等 |
| 需要的数据 | high, low, close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | TP = (H + L + C) / 3；CCI = (TP - SMA(TP, n)) / (0.015 × MD) |
| 参考价值 | ★★★☆☆ 比 RSI 更敏感的超买超卖判断，适合短线交易。但使用频率不如 KDJ/RSI，优先级中等 |

### 10. OBV（能量潮 / On-Balance Volume）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★★☆☆☆ 简单 |
| 需要的数据 | close, volume |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | 当日 close > 前日 close → OBV = prevOBV + volume；反之减去；相等不变 |
| 参考价值 | ★★★☆☆ 量价配合指标，OBV 与价格背离是重要信号。适合辅助判断资金流向，但需要结合价格走势看 |

### 11. ATR（平均真实波幅 / Average True Range）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★★☆☆☆ 简单 |
| 需要的数据 | high, low, close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | TR = max(H - L, H - prevC, prevC - L)；ATR = SMA(TR, n) |
| 参考价值 | ★★☆☆☆ 衡量波动幅度，常用于止损位设置和仓位管理。对趋势判断的直接帮助有限，优先级可放低 |

### 12. DMI/ADX（趋向指标）

| 项目 | 说明 |
|------|------|
| 实现难度 | ★★★★☆ 复杂 |
| 需要的数据 | high, low, close |
| 数据来源 | 已有 K 线数据，无需额外接口 |
| 计算方式 | 计算 +DM/-DM/TR，再计算 +DI/-DI，ADX = SMA(ABS(+DI - -DI) / (+DI + -DI), n) |
| 参考价值 | ★★★☆☆ 趋势强度判断权威指标，ADX > 25 趋势强，ADX < 20 震荡。但计算繁琐，且 A 股散户使用率不高 |

## 实现优先级建议

| 优先级 | 指标 | 理由 |
|--------|------|------|
| P0 | VOL（成交量柱） | 数据已有，几乎零成本，量价分析基础 |
| P0 | KDJ | A 股最常用，计算简单，与现有 BOLL 配合使用效果好 |
| P1 | MACD | 全球标准，趋势判断权威，适合在详情弹窗新增选项卡 |
| P1 | RSI | 超买超卖判断，与 KDJ 互补 |
| P2 | BIAS | 实现简单，已有 MA 数据 |
| P3 | WR / CCI / OBV | 有参考价值但使用频率较低 |
| P4 | EMA / ROC / ATR / DMI | 实现成本或用户认知度考虑，可暂缓 |

## 与现有功能的整合思路

- KDJ / RSI / MACD 可在详情弹窗以选项卡形式展示（如当前"MA & BOLL"旁新增"KDJ"、"MACD"标签）
- VOL 成交量柱可直接叠加在 K 线图下方
- 均支持日/周/月周期切换，数据源共用现有 K 线数据
- 均支持缓存策略，复用现有缓存机制
