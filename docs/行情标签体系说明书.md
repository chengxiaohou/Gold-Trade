# 第一部分：标签设计理论

## 第一层级：趋势结构标签（基于均线排列）

| 标签名称 | 判断方式（量化定义） | 参考价值（实战含义） |
| :--- | :--- | :--- |
| **多头强排列** | 5日 ＞ 10日 ＞ 20日 ＞ 60日 ＞ 120日，且**所有均线斜率向上**（今日值 > 昨日值）。 | **主升浪进攻期**。每一次回踩5/10日线都是高胜算买点。此时只考虑止盈，不考虑止损离场（除非均线结构被破坏）。 |
| **多头弱排列** | 5/10/20日短中期均线在60日之上，但相互缠绕粘合，**5日不再持续创新高**。 | **高位震荡/上涨中继**。趋势未坏，但短期赚钱效应下降。适合高抛低吸，不宜追涨杀跌。 |
| **空头强排列** | 120日 ＞ 60日 ＞ 20日 ＞ 10日 ＞ 5日，且**所有均线斜率向下**。 | **主跌浪/系统性风险**。任何反弹到5/10日线都是标准的“逃命线”。严禁抄底，持仓者应利用反弹止损。 |
| **空头弱排列** | 5/10/20日短中期均线在60日之下，但已**走平粘合**，不再创新低。 | **震荡筑底期**。下跌动能衰竭，但上涨趋势未起。适合小仓位试盘，耐心等待短期均线上穿长期均线的“金叉”确认。 |
| **均线粘合（变盘）** | 5、10、20、60日四条均线最大差值 < 当前股价的 **3%~5%**（搅在一起）。 | **方向选择的前夜（极强信号）**。旧周期结束，新周期即将开启。向上突破粘合区则进入强周期，向下跌破则进入弱周期。 |

## 第二层级：量价关系标签（基于成交量 + 价格）

| 标签名称 | 判断方式（量化定义） | 参考价值（实战含义） |
| :--- | :--- | :--- |
| **量增价升（健康）** | 今日收盘价 > 昨日收盘价，且**今日成交量 > 5日均量线**（放量）。 | **真金白银的拉升**。说明场外资金积极进场，趋势具有持续性。这是强周期最需要的“燃料”，持仓不动是最优解。 |
| **量缩价升（背离/空心）** | 今日收盘价 > 昨日收盘价，但**今日成交量 ＜ 5日均量线**（缩量）。 | **动能衰竭的警告**。说明只是少数散户或游资在拉，大资金不跟进。如果出现在高位，极易形成“诱多”陷阱，需立刻提高警惕。 |
| **量增价跌（恐慌/出货）** | 今日收盘价 < 昨日收盘价，且**成交量 > 5日均量线**（放量下跌）。 | **视位置而定**：出现在高位，是机构**高位出货**，坚决离场；出现在连续大跌的末端，是**恐慌盘涌出**，往往意味着“最后一跌”，距离底部反转极近。 |
| **量缩价跌（阴跌）** | 今日收盘价 < 昨日收盘价，且**成交量 ＜ 5日均量线**（缩量下跌）。 | **无人接盘的阴跌**。虽然跌速不快，但极其磨人。这种走势没有底部可言，除非出现放量恐慌盘或大阳线，否则绝不能抄底。 |
| **地量见地价** | 成交量创出**近20个交易日的最低量**（极度萎缩）。 | **抛售枯竭**。多空双方都躺平了。这往往是中长线大底的前兆，但**不是买入信号**（地量之后还可能持续地量），需等待一根放量阳线来确认。 |

## 第三层级：动能背离标签（基于 MACD / RSI + 价格）

| 标签名称 | 判断方式（量化定义） | 参考价值（实战含义） |
| :--- | :--- | :--- |
| **MACD顶背离（强转弱）** | 股价（K线）创出**新高**，但 MACD 指标（DIF线或红柱高度）**未创新高**，反而降低。 | **上涨发动机熄火（核心风险信号）**。说明内在上涨力量已经跟不上了，即使均线还是多头排列，强周期也已进入尾声。这是最可靠的**减仓信号**。 |
| **MACD底背离（弱转强）** | 股价（K线）创出**新低**，但 MACD 指标（DIF线或绿柱高度）**未创新低**，反而抬高。 | **下跌力量衰竭（核心机会信号）**。说明空头砸不动了，即使均线还是空头排列，弱周期也即将结束。这是最可靠的**准备抄底信号**，只等一根放量阳线确认。 |
| **RSI超买（高位钝化）** | RSI（相对强弱指标，通常看6日或14日）数值进入 **70 或 80 以上**区间。 | **短期情绪过热**。如果出现在强多头排列中，说明处于“强势逼空”状态，可以持仓，但**绝对禁止新开重仓**，因为随时面临技术性回调。 |
| **RSI超卖（低位钝化）** | RSI 数值进入 **20 或 30 以下**区间。 | **短期情绪极度恐慌**。如果出现在空头排列末端，说明市场非理性抛售，但此时不建议盲目割肉。持股者可等待反弹，持币者可关注。 |

## 第四层级：波动率标签（基于布林带 BOLL / ATR）

| 标签名称 | 判断方式（量化定义） | 参考价值（实战含义） |
| :--- | :--- | :--- |
| **布林带开口扩张（上轨外扩）** | 布林带上轨向上翘起，且**股价连续触及并贴着上轨运行**。 | **单边强趋势进行中**。这是加速上涨的标志，持仓者要拿住，享受主升浪。但追高风险极大，因为一旦跌回轨道内，容易产生剧烈回撤。 |
| **布林带开口扩张（下轨外扩）** | 布林带下轨向下翘起，且**股价连续触及并贴着下轨运行**。 | **单边下跌恐慌中**。加速赶底阶段，往往伴随着放量暴跌。此时不要试图接飞刀，必须等待价格重新站回下轨之上。 |
| **布林带收口（挤压）** | 布林带上轨和下轨**间距持续缩小**，带宽（上轨-下轨）/中轨 数值跌入历史低位。 | **大变盘前的宁静（高价值信号）**！波动率被压缩到极致，多空双方即将决出胜负。此时应密切盯着方向：**向上突破中轨**做多，**向下跌破中轨**做空或离场。 |

## 第五层级：综合强弱周期标签（多指标复合）

原始设计将四个维度的标签组合成“交易环境标签”。实际实现见第二部分第五节（定档条件已按打分制落地，并新增“震荡变盘期”）。

| 综合标签 | 组合条件（必须全部满足） | 参考价值（操作策略） |
| :--- | :--- | :--- |
| **强进攻周期** | 均线**多头排列** + 量价**量增价升** + MACD在零轴上方且**无顶背离** + 布林带**上轨温和扩张**。 | **胜率最高的黄金时期**。趋势、量能、动能三方共振。策略：**重仓持有，逢回踩均线加仓，不轻易言顶**。 |
| **强防守周期** | 均线**多头/粘合** + 量价**量缩价升或缩量横盘** + MACD出现**顶背离** + 布林带**收口**。 | **鱼尾行情或变盘前夜**。趋势还在，但内核已弱。策略：**只出不进，逐步减仓，锁定利润，等待方向明朗**。 |
| **弱反弹周期** | 均线**空头排列** + 量价**缩量反弹** + MACD在零轴下方金叉但**无底背离** + 股价触及布林**中轨受阻**。 | **标准的“逃命波”**。大趋势向下，只是超跌反抽。策略：**仓位重的借此机会坚决减仓，持币的继续观望，绝不追高**。 |
| **弱筑底周期** | 均线**空头弱排列（走平/粘合）** + 出现**地量** + MACD出现**底背离** + 布林带**收口**或**下轨外扩后收回**。 | **黎明前的黑暗**。下跌力量衰竭，大资金开始暗中吸筹。策略：**轻仓试盘，急跌敢买，不追高，耐心等待放量大阳线确认反转**。 |

# 第二部分：代码实现现状

> 全部实现在 `components/StockDividendPage.tsx`。单元格与浮窗共用同一套分析函数，保证口径一致。

## 一、三类标签总览

| 类别 | 分析函数 | 单字 | 颜色（单元格） | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 破位类 | `analyzeMarketConditions` | 破 / 修 / 真 / 假 | 绿 / 橙 / 绿 / 红 | 近5日跌破均线事件的观测与定论 |
| K线形态 | `analyzeKlinePatterns` | 十 / 针 / 吊 / 射 / 倒 | 灰 / 红 / 绿 / 绿 / 红 | 仅分析最新收盘交易日，最多1种 |
| 综合周期 | `analyzeEnvironment` | 攻 / 防 / 弹 / 筑 / 震 | 红 / 橙 / 绿 / 靛 / 灰 | 打分制综合强弱周期 |

单元格展示上限 **5 个**（`tags.slice(0, 5)`），顺序为：`[K线形态] [综合周期] [破位类事件…]`。

## 二、破位类标签（analyzeMarketConditions）

**均线周期**：`[5, 10, 20, 30, 60, 120, 250, 500]`，需 ≥ 6 根K线。

**破位判定**：近5个交易日（`lastDays = 5`）内，某日收盘价 **< 均线** 且前一日收盘价 **≥ 前一日均线**（当日向下穿越），记为一次破位事件，`brokenCount` = 当日下穿的均线数量。

**参照均线**：被跌破均线中 **数值最高的一条**（价格下跌时最先触到的那条）。

**3天观测机制**（破位当天计第 1 天）：
- 逐日记录收盘价与参照均线值；
- 3 天内任一天收盘价 **回到均线上方** → **假破位**（`falseBreak`）；
- 观测满 3 天收盘价始终未回 → **真破位**（`trueBreak`）；
- 观测未满 3 天 → **修复观察**（`confirming`）。

**单元格展示规则**（`getLatestDayTags`）：仅展示 **观测窗口覆盖最新交易日** 的事件：
- 当天新破位 → `破`（绿）+ `修`（橙）两个标签；
- 更早的破位仍在观测中 → `修`（橙）；
- 观测窗口恰在最新交易日定论 → `真`（绿）/ `假`（红）。

## 三、K线形态标签（analyzeKlinePatterns）

**基础数据单元**（基于 OHLC）：实体 = |收-开|；上影 = 高-MAX(开,收)；下影 = MIN(开,收)-低；振幅 = 高-低。需 ≥ 21 根K线。

**通用阈值**：小实体 ≤ 振幅×10%；长影线 ≥ 实体×2；十字星实体 ≤ 振幅×5%。

| 形态 | 单字 | 颜色 | 判定逻辑 |
| :--- | :--- | :--- | :--- |
| **十字星** | 十 | 灰 | 实体 ≤ 振幅×5% 且振幅 > 前20日均振幅×10%（排除一字板）。方向结合近20日高低点（高位警示 / 低位关注）。**命中后优先返回，不再判定其他形态**。 |
| **金针探底** | 针 | 红 | 小实体 + 上影 ≤ 实体×30% + 下影 ≥ 实体×2.5 +（MA20向下 或 现价贴近近20日低点）。当日量 > 前5日均量 → 升级为“放量金针”（权重提升）。 |
| **吊颈线** | 吊 | 绿 | 小实体 + 上影 ≤ 实体×30% + 下影 ≥ 实体×2 + MA20向上 且 现价贴近近20日高点。 |
| **射击之星** | 射 | 绿 | 小实体 + 下影 ≤ 实体×30% + 上影 ≥ 实体×2 +（MA20向上 或 贴近近20日高点）。 |
| **倒锤子线** | 倒 | 红 | 小实体 + 下影 ≤ 实体×30% + 上影 ≥ 实体×2 +（MA20向下 或 贴近近20日低点）。 |

> 缩写说明：金针探底用 **“针”** 而非“金”，一是“金”与真破位的“真”在 8px 小字号下字形几乎无法区分，二是“针”更能体现长下影线的针状形态。

## 四、环境标签（analyzeEnvironment）

需 ≥ 130 根K线（120日均线 + 近20日高低点 + 近60日带宽分位 + MACD）。打分制：**均线 30% + 量价 30% + MACD背离 25% + 布林带 15%**。

### 4.1 趋势结构维度（30%）

| 标签 | 单字 | 颜色 | 分数 | 判定 |
| :--- | :--- | :--- | :--- | :--- |
| 多头强排列 | 多 | 红 | +1 | 5>10>20>60>120 且斜率全部向上 |
| 空头强排列 | 空 | 绿 | -1 | 5<10<20<60<120 且斜率全部向下 |
| 多头弱排列 | 弱 | 橙 | +0.4 | 5/10/20 在60日之上，但未达强排列 |
| 空头弱排列 | 空弱 | 灰 | -0.4 | 5/10/20 在60日之下，但未达强排列 |
| 均线粘合 | 粘 | 灰 | 0 | 5/10/20/60 最大差值 < 股价×4% |

### 4.2 量价关系维度（30%）

| 标签 | 单字 | 颜色 | 分数 | 判定 |
| :--- | :--- | :--- | :--- | :--- |
| 量增价升 | 增 | 红 | +1 | 收 > 昨收 且 量 ≥ 5日均量 |
| 量缩价升 | 缩 | 橙 | +0.2 | 收 > 昨收 且 量 < 5日均量 |
| 量增价跌 | 跌 | 绿 | -1 | 收 < 昨收 且 量 ≥ 5日均量 |
| 量缩价跌 | 阴 | 灰 | -0.2 | 收 < 昨收 且 量 < 5日均量 |
| 地量见地价 | （追加说明） | — | 分数 +0.4（封顶1） | 当日量 = 近20日最低 |

### 4.3 动能背离维度（25%，MACD 为主、RSI 辅助）

- **顶背离**（-1，单字“顶”，绿）：近20日价格高点出现在 ≤3 日前，且当日 DIF 较高点日显著走低（跌幅 > |DIF|×0.5%）。
- **底背离**（+1，单字“底”，红）：近20日价格低点出现在 ≤3 日前，且当日 DIF 较低点日显著抬高。
- **无背离时**：基础分 = (DIF > DEA ? +0.4 : -0.4) + (DIF > 0 ? +0.3 : -0.3)，按金叉/死叉/中性给单字“金/死/中”；
  - RSI6 ≥ 80 → -0.25；≥ 70 → -0.15（超买过热）；
  - RSI6 ≤ 20 → +0.25；≤ 30 → +0.15（超卖恐慌）；
  - 总分截断在 [-1, 1]。

### 4.4 波动率维度（15%，BOLL 20,2）

带宽 = (上轨-下轨)/中轨，取近60日带宽的 20% 分位作参照：

| 标签 | 单字 | 颜色 | 分数 | 判定 |
| :--- | :--- | :--- | :--- | :--- |
| 布林收口 | 收 | 灰 | 0 | 带宽 < 近60日20%分位 |
| 上轨扩张 | 涨 | 红 | +1 | 价 ≥ 中轨+70%带宽 且上轨上升 |
| 下轨扩张 | 跌 | 绿 | -1 | 价 ≤ 中轨-70%带宽 且下轨下降 |
| （其他） | — | — | ±0.3 | 价在中轨上方 +0.3 / 下方 -0.3 |

### 4.5 综合强弱周期（打分定档）

`综合得分 = 0.3×趋势 + 0.3×量价 + 0.25×动能 + 0.15×波动`。`bear = 趋势分 ≤ -0.4`。

| 周期 | 单字 | 颜色 | 定档条件 |
| :--- | :--- | :--- | :--- |
| **强进攻周期** | 攻 | 红 | 综合得分 ≥ +0.6 |
| **弱筑底周期** | 筑 | 靛 | 综合得分 ≤ -0.6 |
| **强防守周期** | 防 | 橙 | 得分 ≥ +0.2 且（顶背离 或 量缩价升 或 收口） |
| **弱筑底周期** | 筑 | 靛 | 得分 ≤ -0.2 且 bear 且（底背离 或 地量 或 收口） |
| **弱反弹周期** | 弹 | 绿 | 得分 ≤ -0.2 且 bear |
| **震荡变盘期** | 震 | 灰 | 其余情况 |

## 五、单元格展示规则（getLatestDayTags）

- **数据来源**：日线K线（取自 BOLL 日线缓存 `stockBollMap`）。
- **展示位置**：股票名称下方第二行，居中，最多 **5 个**标签，单字 + 边框标签样式（`text-[8px]`、`rounded`、半透明底色）。
- **顺序**：`[形态单字] → [周期单字] → [破位类事件]`（破位事件按时间先后，最旧在前）。
- **缓存**：`latestTagsCache` 以 klines 引用 + 版本号（`LATEST_TAG_VERSION`，当前 **v6**）为键；**标签文本/逻辑变更时必须 +1 版本号**，否则 HMR 会保留旧缓存导致改动不生效。
- **交互**：名称列表头（“股票名称/代号”）下的小表头可点击，在“状态标签 / 代码”两种第二行展示模式间切换，默认展示标签。

## 六、浮窗展示规则（涨跌幅列）

- **交互**：悬停临时显示、点击固定常驻、点击外部关闭（与价格浮窗一致的交互体系）。
- **结构**（自上而下）：
  1. 标题：股票名称 + 代码（居中）；
  2. **环境标签行**：cycle + 各维度触发的全部标签（趋势/量价/动能/波动），cycle 标签额外显示综合得分（如“强进攻周期 +0.72”）；
  3. “近5交易日行情”分组：**最新形态**（完整名称）→ **破位事件**（时间倒序，最新在上）；
  4. **判定依据区**：悬停/点击某标签后展示该标签的判定理由与必要数据；默认选中最新日期的“破位”事件。
- 破位事件行 = `破位 xN`（绿，N=下穿均线数）+ 状态徽标 `真破位 / 假破位 / 修复观察 xN`。

## 七、颜色与样式约定
