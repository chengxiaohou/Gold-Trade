## 〇、核心交易理念（纪律层）

博主反复强调的底层纪律，是整套逻辑的前提：

1. **不要把盘感当预测**：操作要有「分析 → 计划 → 盘中执行 → 复盘」的闭环，分析在盘前，执行在盘内，突发情况要有预备预案。
2. **散户三大特性 = 亏损根源**：① 追涨杀跌；② 不舍得卖、不敢买；③ 情绪化严重。
3. **不做“开超市”**：几十个板块没有精力全追，只做自己擅长的板块。
4. **保住本金优先**：普通人目标设定为「跑赢银行利率 + 跑赢通胀」，而非暴富。
5. **要信就早信，不信就别追高**：低位早买，回调继续买；追涨杀跌是牛市散户亏钱的主因。

## 一、选股逻辑

### 1.1 板块选择
- 博主观盘以**板块为基本单位**，先判断大方向再定个股。
- **板块轮动/高低切**是主线逻辑：资金有限，只能“女娲补天”，哪里利好涨哪里；板块间轮流拉升（东升西落）。
- 板块结构分工：主线是金融（慢抬升、影响指数），冲锋是科技和医药，稳定是能源，政策拉动靠消费等“活水”。
- 买一个板块只有两个理由：**看好后续利好动作**，或**看好业绩反转**（更好，或不能再差）。
- 高位板块节奏：不是一直拉，拉到滞涨分时区会**休息 2-3 天再继续**。

### 1.2 个股标的分类（先定“属于哪类”再决定打法）
| 类型 | 特征 | 打法 |
| :--- | :--- | :--- |
| **低位埋伏** | 低位未启动 | 缩量入场、分批建仓（见 2.2） |
| **连续放量强势** | 已放量启动 | 突破均线加仓、回踩放量加满 |
| **抱团走趋势** | 慢慢涨，约 45° 斜率 | 趋势票不跌破平台**无需卖** |
| **超跌反弹** | 跌透后的修复 | 抢反弹只买**最强板块**，冲高即卖 |
| **题材股/情绪票** | 事件催化的短线 | 首板/连板、龙头战法，反应快、股权重小 |
| **业绩反转** | 困境反转（光伏/军工） | 低位重仓埋伏，看半年报、减持节奏 |

### 1.3 如何判断一只票“能不能买”
- **买入要有理由**：连日线都突破不了，要么主力闷声做大事，要么是惊吓——此时要复盘当初看好的理由是否还存在。
- **看业绩 + 看减持**：机构大基金扎堆但无增持、频繁减持的板块难大涨；看个股在高位还是低位，再研究其何时发半年报。
- **区分独立行情 vs 板块共振**：共振上涨（如稀土）跟龙头板块；独立行情（如芯片前段）看个股自身逻辑。做日内 T 时多数板块参考**创业板指数**，连板/独立行情/中字头大票除外。
- **性价比权衡**：业绩龙头确定性高、机构调研多，但资金不足时性价比反而不高（跑不过小票）。
- **避开有“前科”的票**：注意减持、突发利空、业绩杀风险。

### 1.4 三大宏观风险节点
每年三个节点必须控风险：**三月前后、十一月、年前半月**。这三个时段行情异常，需警惕减持、调查、业绩杀等集中冲击。

## 二、仓位管理

### 2.1 按资金分档（“只买几只”上限）
| 资金规模 | 最多持仓数 |
| :--- | :--- |
| < 2 万 | 1 只 |
| < 10 万 | 2 只 |
| < 50 万 | 3 只 |
| 50-100 万 | 4 只 |

中长线（持股 6 个月以上）的可另算。持仓越多、轮动越频繁，散户操作越不过来。

### 2.2 低位埋伏的建仓路径（全文最具操作性的量化流程）
1. 先定类型：**低位埋伏** 还是 **连续放量继续看好**（两类打法完全不同）。
2. 低位埋伏：**日线看好 + 缩量入场**，先买 **1-2 层**仓位。
3. **三日内继续缩量** → 加仓到 **3 层**，之后“看戏”。
4. 连续 15 天**未突破日线** → 重新问自己“当初看好的理由还在不在”；若短期无理由，在「止损止盈离场」或「转为中线」中选择。
5. 上涨后**突破五日线放量加仓 1 层** → 达到约 **4.5 层**；两个票合计约 9 层多。

### 2.3 高位滚动仓位档位（波段式加减）
- 高位滞涨时间：仓位限制在 **8 层以内**；3550 点突破时博主减到 **7 层**。
- **回踩放量 = 满仓加进去**（具备条件时直接打满）。
- **突破新高但量能不足** → 获利减仓。
- **暴跌 1 个点级急跌**（大涨大跌极端） → 反向接回/加满。

> 一句话口诀：**低位好票中线“纹丝不动”甚至回调加仓；高位票滚动高抛低吸，只留底仓。**

## 三、择时信号（操作层级划分）

把操作按周期拆成三层，各管各的，互不混淆：

| 层级 | 看什么 | 管什么 |
| :--- | :--- | :--- |
| **分时操作** | 分时线、分时支撑位、分时量柱 | 当日进出、做 T、清高抛低吸 |
| **日线操作** | 5/10/20 日线、成交量 | 加减仓、止损 |
| **中长线/中线** | 日线 + 资金 + 选票 | 配置 6 个月以上标的 |

- 总结：**操作看分时，加减仓看日线，止损看日线，止盈看滞涨。**
- 没时间盯盘的散户 → 统一规划为**中线**：低位买入满仓，设好止盈/止损价位，一刀切执行。
- 短线分两种：**超短线 = 龙头战法**（首板/连板/分歧转一致/穿越龙）；**短线 = 预判重要会议、重大发布、重大重组、政策**，需要多看新闻、扩股票池。

### 4.3 汇总展示与公式口径（替代 `加仓 xN / 减仓 xN`）

去掉 `xN`（“命中几个”／“连续几天”语义废弃），改为**显示当日该方向置信度总分**（Σ 当日该方向各信号分）：

| 展示 | 计算 | 说明 |
| :--- | :--- | :--- |
| `加仓 0.85` | Σ 各买信号分 | 当日买信号分数求和；可 >2（多个信号/多条款叠加） |
| `减仓 1.20` | Σ 各卖信号分 | 当日卖信号分数求和；可 >2 |

- 纯条件不成立 → 不显示，不计入求和。
- 每个条款：**标准达成 0.5** → **超额：在 `0.5~2.0` 间平均分配**（每优于标准 1% +0.15，超额 10% 到满 2.0）；依赖容差则 `0.5 × (1 - 用掉容差比例)`。
- **判定依据展示得分公式的计算过程**（实时悬停/详情），例：

  > ⑥缩量入场：低位=0.5-(1.040-1.000)/(1.050-1.000)×0.5=0.100 ＋ 缩量=0.5+(1.00-0.37)×0.15×...→ 详见实现
  
  公式均代入实际数据（价格/量比），可自行复核。
- 容差上限全部取设置页“标签判定参数”（`tagParams`）现值；关闭某参数的开关会禁用对应条款。

## 五、与项目现有标签的重合分析（买卖信号 vs 行情标签）

比对对象：项目股票名列表下方标签体系（实现于 `components/StockDividendPage.tsx`），共四类：
**破位类**（破/修/真/假）、**K线形态**（十/针/吊/射/倒）、**环境周期与维度**（攻/防/弹/筑/震 + 趋势/量价/波动维度）、**每日行情信号**（MACD金叉/死叉、放量上涨、放量下跌、极度缩量）。

### 5.1 高度重合（同一信号，两侧都覆盖 → 决策重点）
| 博主买卖信号 | 项目已有标签 | 重合点 / 差异 |
| :--- | :--- | :--- |
| **量价齐升→继续看多**（4.3） | `量增价升`（增/红）、日信 `放量上涨` | 语义完全一致：放量上涨=多 |
| **放量下跌**（高位出货/末端恐慌） | `量增价跌`（增/绿）、日信 `放量下跌` | 一致，且博主同样区分“高位出货 vs 大跌末端”两个位置口径。**建议合并** |
| **无量/缩量急拉卖出、滞涨**（4.2.1） | `量缩价升`（缩/红=诱多警示）、日信 `极度缩量` | 博主=明确卖点；项目=警戒（诱多/变盘前宁静），方向一致但强度不同。**可叠加** |
| **缩量阴跌不抄底，缩量止跌才买** | `量缩价跌`（缩/绿=阴跌不抄底） | 买点端博主多一个“缩量止跌加满”，项目只在量缩价跌的 detail 提到等大阳线。**互补** |
| **破位看修复，不拉回执行纪律** | `破/修/真/假`（3天观测+真假定论） | 博主只有“修复观察”层面；项目的 3 天观测/真假判定更完善。**以项目为准** |
| **放量跌破5/10日，2日不收复10日线→转弱** | `破位类` + 破位观测 | 项目破位以“收盘<均线”下穿为触发，无“收复时间窗”独立判定。**博主补充点** |
| **急跌破 20 日线当天不拉回→止损** | 破位类的均线 `[5,10,20...]` | 项目检测下穿但**无“20日线止损”的独立标签**。**潜在新增** |
| **均线粘合→变盘、突破前高强压力** | `均线粘合`（粘/灰）、波动 `布林收口` | 博主用“突破前高压力+缩量止跌”表达类似变盘逻辑。方向一致，表达不同 |

### 5.2 博主有、项目标签没有（**待新增/待评估的空白维度**）
| 类别 | 博主信号 | 项目现状 |
| :--- | :--- | :--- |
| **分时维度** | 跌一档分时加一层、跌破分时无量买入、分时无量直线抛 | 项目标签纯日线，无分时 |
| **量能绝对阈值** | 1.8 万亿才突破、缩量止跌、新高量能不足 | 项目只有相对 5 日均量的倍数，无绝对量能/止跌判定 |
| **涨停/情绪结构** | 急拉不涨停减、封板打开减、情绪高点抛 | 项目无涨停结构与情绪标签 |
| **持仓管理信号** | 获利减仓、涨太快减、鱼尾不吃、新高量能不足 | 项目把这些归为操作建议文案，非独立标签 |
| **平台/趋势线** | 跌破平台离场、跌破趋势线穿10日线 | 项目无“平台/趋势线”概念 |

### 5.3 项目有、博主几乎不用的（项目独有，保留即可）
- **K线形态**（针/吊/射/倒/十）：博主全文几乎不涉及，仅零星提“十字星”。
- **布林带扩张/收口**、**MACD顶底背离**（项目仅保留金叉/死叉信号）：博主观盘基本不用 BOLL/MACD 定量侧面。

### 5.4 重合处理建议（供决策）
1. **量价四象限（增/缩+涨跌）与博主买卖点**：本质同一体系，建议**保留项目量价标签为主**，把博主的“放量下跌位置口径”“缩量止跌买点”“无量急拉卖点”以更丰富 detail 文案并入现有 detail，避免新增重复标签。
2. **破位类**：项目 3 天观测/真假判定已覆盖博主“看修复”，**以项目为准**；可考虑新增“具 20 日线下穿止损”与“2 日不收复转弱”两个明确观察标签（填补博主独有、项目缺失项）。
3. **分时/量能阈值/涨停结构**：若做成标签，属于**全新维度**，需另建独立 label 体系，不并入现有四类，避免打乱单元格展示上限（5 个）与颜色约定。
4. **重叠标签的去重**：优先复用已有的 `量增价升/量缩价升/量增价跌/量缩价跌` + 每日信号 `vol-up/vol-down/vol-shrink`，在 detail 或图例中体现博主的买卖语义，而非新建同类单字。

## 六、情绪与市场结构观察

- **股票只分两种**：抱团走趋势（45° 慢涨） vs 超跌反弹（急拉快走）。
- **主流板块都会轮到一个遍**（约 40+ 板块），低位板块安心持有/加仓即可，等轮动到位再高抛。
- **龙头是板块的风向标**：看板块就盯龙头，龙头不跌不轻易减仓，龙头怎么走就怎么操作。
- **情绪高点是卖点**：情绪达到短期高点即抛；情绪最热时警惕追高。
- 科创板是情绪集中地（小盘科技股多），**分时做 T 优先参考创业板/科创板指数**。

## 七、总纪律 & 常见误区

- 操作是**纪律执行**，不带情感因素；最怕“有感情地追涨杀跌、开超市”。
- 有利润的卖出就是正确的，**不要怕卖飞**，更不要后悔。
- 不要满目追涨，不追高；不确定就宁可不买，至少要等回调再买。
- 学会沉淀与管理：做板块分析、财务、个股选取、分时操作、仓位管理，加上国际时政，胜过大多数散户。
- 指数重要但别被控盘指数迷惑——**指数稳步突破前，重个股重板块，抓方向不抓点数**。
